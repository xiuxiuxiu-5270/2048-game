# 2048 Game 🎮

欢迎来到经典2048游戏的在线版本！这是一个使用纯HTML、CSS和JavaScript构建的网页游戏。

## 🌐 在线访问

**GitHub Pages:** [https://xiuxiuxiu-5270.github.io/2048-game/](https://xiuxiuxiu-5270.github.io/2048-game/)

## 🎯 游戏目标

通过滑动合并数字，最终合成2048！

## 🎮 如何游玩

1. **打开游戏**: 访问 GitHub Pages 链接即可开始游戏
2. **移动数字**: 使用键盘方向键 ↑ ↓ ← → 移动所有数字
3. **触屏操作**: 支持移动端触屏滑动操作
4. **合并规则**: 相同的数字碰撞时会合并成它们的和
5. **获得分数**: 每次合并都会获得相应的分数
6. **赢得游戏**: 当合成2048时，你获胜了！
7. **新游戏**: 点击"新游戏"按钮重新开始

## ✨ 功能特点

### 核心游戏功能
- 🎯 **完整游戏逻辑**: 实现经典的2048滑动合并玩法
- 🎨 **经典配色**: 还原原作的视觉风格
- 📊 **分数系统**: 实时显示当前分数和历史最高分
- ⏱️ **计时功能**: 实时显示游戏时长
- 💾 **数据持久化**: 最高分保存在浏览器本地存储中
- 🎉 **胜负判定**: 支持胜利和失败两种游戏状态

### 三期迭代新增功能
- 👤 **个人简历页面**: 游戏顶部导航添加跳转入口
- 🏆 **排行榜系统**: 支持自定义玩家昵称、按分数/游玩时间双排序、一键清空本地记录
- 🎖️ **成就系统**: 首次通关、满分挑战、速度之王三项成就，达成自动弹窗解锁
- 📤 **分享功能**: 生成成绩分享文本，一键复制剪贴板
- 🎬 **加载动画**: 游戏启动添加封面+加载动画
- 📖 **新手引导**: 首次打开弹窗展示玩法说明，勾选关闭后永久不再弹出
- 📱 **移动端适配**: 完美支持触屏滑动操作
