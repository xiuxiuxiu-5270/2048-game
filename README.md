# 2048 Game 🎮

欢迎来到经典2048游戏的在线版本！这是一个使用纯HTML、CSS和JavaScript构建的网页游戏。

## 🎯 游戏目标

通过滑动合并数字，最终合成2048！

## 🎮 如何游玩

1. **打开游戏**: 访问 GitHub Pages 链接即可开始游戏
2. **移动数字**: 使用键盘方向键 ↑ ↓ ← → 移动所有数字
3. **合并规则**: 相同的数字碰撞时会合并成它们的和
4. **获得分数**: 每次合并都会获得相应的分数
5. **赢得游戏**: 当合成2048时，你获胜了！
6. **新游戏**: 点击"新游戏"按钮重新开始

## ✨ 功能特点

- 🎯 **完整游戏逻辑**: 实现经典的2048滑动合并玩法
- 🎨 **经典配色**: 还原原作的视觉风格
- 📊 **分数系统**: 实时显示当前分数和历史最高分
- 💾 **数据持久化**: 最高分保存在浏览器本地存储中
- 🎉 **胜负判定**: 支持胜利和失败两种游戏状态
- 📱 **响应式设计**: 适配不同屏幕尺寸

## 🛠️ 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage (数据持久化)

## 🚀 快速开始

1. 克隆仓库到本地
2. 直接用浏览器打开 `index.html` 文件
3. 开始游戏！

或者访问部署的 GitHub Pages 在线游玩。
